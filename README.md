# SWYNEX Exploratory Data Analysis

## Task 2 - Exploratory Data Analysis:

This project is part of my SWYNEX internship.The objective of this task is to perform Exploratory Data Analysis (EDA) on the cleaned dataset prepared during Task 1.

## Dataset:

The analysis uses the cleaned music dataset from Task 1,
- Records: 50,000
- Columns: 33

## Tools Used:

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- VS Code

## Analysis Performed:

- Dataset overview
- Statistical analysis
- Missing value analysis
- Duplicate analysis
- Genre analysis
- Stream count analysis
- Release year analysis
- Popularity analysis
- Audio feature analysis
- Correlation analysis
- Explicit music analysis
- Data visualization
- Trend and anomaly identification

## Key Insights:

1. R&B has the highest number of tracks in the dataset.
2. Stream counts are highly right-skewed, with a relatively small number of tracks having exceptionally high stream counts.
3. Alternative has the highest average stream count among the genres int he dataset.
4. Popularity has a positive relationship with stream count.
5. Individual audio features such as energy, tempo and danceability show weak linear relationship with stream count.
6. The dataset contains music records from multiple release years, allowing release trends to be explored.

## Conclusion

The exploratory data analysis helped identify important patterns, trends and relationships in the music dataset. Statistical analysis and visualizations provided useful insights into genres, streaming performance, popularity and audio characteristics
